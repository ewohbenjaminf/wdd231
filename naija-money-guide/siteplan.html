01

Identity and branding

Site Name

Naija Money Guide

The name combines "Naija," a familiar informal name for Nigeria, with "Money Guide," which clearly communicates the website's subject and purpose. It is memorable, easy to understand, and signals that the information is intended for people making everyday financial decisions in Nigeria.

Proposed domain: naijamoneyguide.com (availability has not been checked).

02

What the website provides

Site Purpose

Naija Money Guide will provide clear, practical and beginner-friendly personal finance education for people in Nigeria. The website will explain basic budgeting, saving habits, spending awareness and everyday money-management concepts using examples that reflect common Nigerian financial situations.

Visitors will be able to explore educational money-management tips, review practical guidance, and use a simple budgeting form to organise an example monthly budget. The website is educational and will not provide personalised investment, tax or legal advice.

Target audience Students Young adults Workers Households First-time budgeters

Visual identity

Color Schema

The palette uses deep green as the primary brand color, warm gold as an accent, soft off-white as the background and dark charcoal for readable text. This palette is applied throughout this document.

Contrast note: Gold is mainly reserved for accents rather than long text. Body text uses charcoal on light backgrounds.

07

Planning ahead

Planned Website Structure

The completed website is planned to contain three main pages:

  • Home: Introduces the website and highlights personal finance topics.
  • Budget Planner: Provides a form and guidance for organising income and expenses.
  • Money Tips: Presents practical educational tips loaded from a local JSON data file.

JavaScript will fetch the JSON data with asynchronous error handling, generate at least 15 content items with at least four data properties each, save an appropriate user preference or budget state in local storage, and provide an accessible modal. The form will display submitted data on a separate form-action page.
